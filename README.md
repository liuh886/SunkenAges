# Museum Below / 潮下博物馆

> 潜入沉没的过去，展出你所相信的真相。

`Museum Below` 是一款围绕深海沉船打捞、文明考古与博物馆策展展开的叙事探索游戏原型。

## 核心循环

1. 根据海图选择沉船遗址。
2. 在氧气与承载量限制下探索、扫描和打捞。
3. 返回博物馆，将遗物放入文明时间线和调查墙。
4. 以证据链支持历史判断，并接受星际游客的质疑。
5. 通过收入、信誉和人物关系解锁更深海域。

## 原型范围

首个可玩原型验证一个完整闭环：

- 一处浅海沉船遗址；
- 氧气、承载量、环境危险和遗物打捞；
- 三件可以形成证据链的遗物；
- 返回博物馆后策划首个展览；
- 游客反馈、收入与学术信誉变化。

原型使用零依赖 HTML、CSS 和 JavaScript，可直接部署到 GitHub Pages。

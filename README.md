# 沉没纪元 / Sunken Ages

> 潜入沉没的过去，展出你所相信的真相。

《沉没纪元》是一款围绕异星深海沉船打捞、文明考古与博物馆策展展开的叙事探索游戏。玩家通过遗物、航线和现场记录建立证据链，逐步揭示一个海洋文明从生态危机走向毁灭的过程。

## 当前可玩闭环

1. 根据海图进入盐雾航道沉船遗址。
2. 在氧气、载重、洋流和生物危险下完成打捞。
3. 返回博物馆，将遗物放入文明时间线和调查墙。
4. 选择历史主张，以证据链发布专题展览。
5. 在经营收入、学术信誉和星际游客的新解释之间作出取舍。

## 技术架构

- **React 19**：任务简报、博物馆策展、结果与 PWA 界面。
- **Phaser 4**：独立的深海探索运行时，进入下潜阶段时按需加载。
- **TypeScript**：领域规则、游戏事件和界面契约均采用严格类型。
- **Vite 8**：开发服务器、代码分包与 GitHub Pages 生产构建。
- **Workbox / vite-plugin-pwa**：安装提示、离线缓存、版本更新与 standalone 模式。
- **Vitest**：验证证据门槛以及收入/信誉的核心规则。

游戏运行时与博物馆界面通过窄接口通信。后续新增沉船、角色关系、展览主题或存档系统时，不需要修改 Phaser 与 React 的内部实现。

## 本地运行

```bash
npm install
npm run dev
```

生产验证：

```bash
npm run typecheck
npm run test
npm run build
npm run preview
```

## PWA

生产版本支持：

- 安装到桌面或移动设备；
- 已访问内容离线启动；
- 新版本发现与主动更新；
- GitHub Pages 子路径 `/MuseumBelow/`；
- 桌面键盘和移动端触控操作。

## 部署

Pull Request 必须通过类型检查、领域测试、生产构建和 PWA 产物检查。合并到 `main` 后，GitHub Actions 只部署 `dist/` 到 GitHub Pages。

# 沉没纪元 / Sunken Ages

> 潜入沉没的过去，展出你所相信的真相。

《沉没纪元》是一款围绕异星深海沉船打捞、文明考古与博物馆策展展开的叙事探索游戏。玩家通过遗物、航线和现场记录建立证据链，逐步揭示一个海洋文明从生态危机走向毁灭的过程。

## 当前可玩内容

### 第一关：盐雾航道

- 在浅海民用运输船中回收三件撤离证据；
- 应对洋流、刺胞生物、氧气与载重限制；
- 在“有序撤离”和“选择性撤离”之间建立首个专题展。

### 第二关：潮门避难站

- 从任务台直接选择，或完成第一关后自动推进；
- 扫描外部控制台，开启隔离闸门；
- 避开周期性压力喷口与深海危险；
- 四件证据总重量超过货舱上限，必须主动取舍；
- 判断潮门站究竟是秘密避难所，还是长期运行的封锁设施。

## 核心闭环

1. 从任务台选择调查地点并阅读声呐简报。
2. 在氧气、载重、洋流和环境危险下完成打捞。
3. 返回博物馆，将遗物放入文明时间线和调查墙。
4. 选择历史主张，以证据链发布专题展览。
5. 在经营收入、学术信誉和星际游客的新解释之间作出取舍。

## 技术架构

- **React 19**：任务台、博物馆策展、结果与 PWA 界面。
- **Phaser 4**：独立的深海探索运行时，进入下潜阶段时按需加载。
- **TypeScript**：关卡数据、领域规则、游戏事件和界面契约采用严格类型。
- **Vite 8**：开发服务器、代码分包与 GitHub Pages 生产构建。
- **Workbox / vite-plugin-pwa**：安装提示、离线缓存、版本更新与 standalone 模式。
- **Vitest**：验证关卡数量、证据门槛、载重取舍以及收入/信誉规则。

关卡内容由数据定义，游戏运行时与博物馆界面通过窄接口通信。新增沉船、角色关系和展览主题时，不需要复制整套场景逻辑。

## 本地运行

```bash
npm install
npm run dev
```

生产验证：

```bash
npm run typecheck
npm run test
npm run build
npm run preview
```

## PWA

生产版本支持：

- 安装到桌面或移动设备；
- 已访问内容离线启动；
- 新版本发现与主动更新；
- GitHub Pages 子路径 `/SunkenAges/`；
- 桌面键盘和移动端触控操作；
- 本地记录已经完成的调查关卡。

## 部署

Pull Request 必须通过类型检查、领域测试、生产构建和 PWA 产物检查。合并到 `main` 后，GitHub Actions 只部署 `dist/` 到 GitHub Pages。
